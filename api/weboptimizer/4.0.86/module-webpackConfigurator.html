(inner) deferTransformer(transformer)

Converts a legacy (postcss 7) plugin into a visitor based one which runs after all other plugins have finished. NOTE: Postcss 8 runs legacy plugins during its initial root pass which happens before any visitor based plugin (like "postcss-mixins" or "postcss-nested") had the chance to resolve its constructs. A legacy plugin would therefore see (and modify) not yet resolved declarations like mixin definitions and its modifications would get lost during their later expansion.

Name Type Description
transformer Legacy plugin to defer.
